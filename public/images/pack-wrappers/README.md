# Pack wrapper art

The Holo foil, Keycaps, Cassette, Kraft parcel and Anti-static bag wrappers (November 2026) are Blender models built and rendered
for this site, with no external models, textures or photographs. The letters on the keycaps and the
side mark on the cassette are set in Tracker Round (SIL Open Font License 1.1, `public/fonts/TrackerRound-OFL.txt`).
The bag's caution label is drawn for this site: a plain triangle round the site's own three bars, with no
standard hazard symbol or wording.

Each wrapper is the whole pack front at 600x1000, a back without its centrepiece, and for some a
cut-out (`-tint-`) of the parts that take the pack's colour. The number in a file name is its
version: `/images/` is served cache-first, so changed art gets a new number (`src/components/packs/wrapperArt.ts`).
