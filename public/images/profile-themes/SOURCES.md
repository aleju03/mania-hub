# Profile theme sprites

Art the profile theme shaders draw (`src/lib/profile-theme-gl.ts`, `THEME_SPRITES`).

| File | Theme | Source | Licence |
|---|---|---|---|
| `lantern.png` | Hanabi | A paper lantern (chochin) modelled and rendered for it in Blender (Cycles) from a script in the site owner's 3D project (`3d-modelling/chochin/build_chochin.py`); the shader tints it red or orange and flickers it | Own work |
| `palm.png` | Vaporwave | "Detailed palm tree silhouette", https://openclipart.org/detail/317990/detailed-palm-tree-silhouette (scaled, kept as an alpha mask the shader tints) | Public domain (Openclipart, CC0) |
| `maple-built.webp` | Autumn maple | A forest path built and rendered for it in Blender (Cycles) by a script in the site owner's 3D project (`3d-modelling/theme-maple-path/build_maple_path.py`), with its depth pass packed below at half size; trees and leaf litter generated in the script with the leaf photos below as leaf cards, bark, ground, ferns, rocks and the HDRI from Poly Haven (CC0, listed in that folder's README); the beams' shimmer is drawn in the shader | Own work (CC0 assets) |
| `maple-leaves-2x.webp` | Autumn maple | Eight leaves cut from four photographs on Pixabay (https://pixabay.com/photos/leaves-autumn-tree-maple-season-3348691/, https://pixabay.com/photos/leaves-maple-branch-autumn-fall-3417363/, https://pixabay.com/photos/fall-leaves-leaf-transparent-1768376/, https://pixabay.com/photos/fall-leaves-leaf-transparent-1768364/), two recoloured crimson and russet, 4x2 in 512 px cells; drawn as lit 3D leaves by the overlay | Pixabay Content License |
| `firefly-built.webp` | Firefly forest | A forest clearing built and rendered for it in Blender (Cycles) by a script in the site owner's 3D project (`3d-modelling/theme-firefly-forest/build_firefly_forest.py`), with its depth pass packed below at half size; trees grown in the script, plants, rocks, bark, ground and moss from Poly Haven and ambientCG (CC0, listed in that folder's README); the fireflies, mist and parallax are drawn in the shader | Own work (CC0 assets) |
| `aero-built.webp` | Aero | Glossy leaves beaded with water drops on an aqua bokeh, modelled and rendered for it in Blender (Cycles) by scripts in the site owner's 3D project (`3d-modelling/theme-aero/build_aero_macro.py`), with its depth pass packed below at half size and a sheet of eight soap bubbles (`build_aero.py --bubbles`) beside it; the bubbles' reflections use Poly Haven's `kloofendal_48d_partly_cloudy_puresky` HDRI (CC0); the rising bubbles, ripples and parallax are drawn in the shader | Own work (CC0 assets) |
